# p2p-chess

Шахматы в браузере с мультиплеером в реальном времени. Игра происходит напрямую между браузерами игроков через WebRTC — без серверов, баз данных и регистрации.

## Как играть

1. Открой сайт https://bluvakint.github.io/p2p-chess/
2. Скопируй ссылку (кнопкой или через QR-код) и отправь другу.
3. Оба нажмите «Готов» — игра началась.

Никаких аккаунтов. Состояние игры не сохраняется на сервере.

## Возможности

- Полные правила шахмат: все ходы, рокировка, взятие на проходе, превращение пешки с выбором фигуры.
- Завершение партии: мат, пат, ничья по соглашению, ничья по правилу 50 ходов и троекратному повторению.
- Контроль времени: 5, 10, 15 минут или произвольное значение.
- Управление: перетаскивание фигур (мышь и тач) + классические клики.
- Звуковые эффекты, синтезированные через Web Audio API (без внешних файлов).
- Шахматная нотация с возможностью копирования.
- Подсветка возможных ходов, последнего хода и шаха.
- Адаптивный интерфейс для десктопа и мобильных.
- QR-код для быстрого приглашения.
- Если мастер отключается, второй игрок автоматически становится мастером новой комнаты.

## Технологии

- **Vanilla JavaScript (ES Modules)** — без фреймворков и сборщиков.
- **PeerJS** — обёртка над WebRTC для P2P-соединения.
- **chess.js** — валидация ходов и логика правил.
- **Web Audio API** — синтез звуков в браузере.
- **qrcode.js** — генерация QR-кодов.

## Запуск локально

Проект использует ES Modules, поэтому его нельзя открыть двойным кликом по файлу — нужен локальный HTTP-сервер.

**VS Code + Live Server:**
Установи расширение Live Server и нажми «Go Live».

**Python:**
```bash
python -m http.server 8000
```

**Node.js:**
```bash
npx serve
```

После запуска открой `http://localhost:8000` (или другой порт) в двух вкладках или разных браузерах для проверки P2P.

## Как это работает

PeerJS-сервер используется только как «сваха»: он помогает браузерам узнать IP-адреса друг друга. После этого соединение устанавливается напрямую между игроками, и все ходы передаются без участия сервера.

Комната идентифицируется коротким ID в URL (`?room=abc123`). Этот ID — не IP-адрес, а имя в сети PeerJS.
